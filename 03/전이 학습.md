# 전이 학습이란

전이 학습(transfer learning): **다른 데이터를 이용해 이미 학습된 모델을 가져와 현재 나의 데이터에 최적화시키는 학습 방법**

- 대용량 데이터를 이용해 사전 학습한 모델을 **소규모 데이터**에 최적화시키는 방식으로 활용
- 파인 튜닝(fine-tuning)은 전이 학습의 한 종류로, 이미 학습된 모델을 가져와 나의 데이터에 최적화하는 것

```
사전 학습된 모델(대규모 데이터, 예: ImageNet) → 분류층 재정의 → 내 데이터로 재학습
```

- 보통은 특징 추출 부분(합성곱층)은 그대로 두고, **마지막 분류층(MLP)만 새로 정의**해 학습함
- 데이터가 적을 때 처음부터 학습하는 것보다 훨씬 적은 데이터·시간으로 높은 성능을 얻을 수 있음

# VGG-16 구조

1. 합성곱 + ReLU
2. 최대 풀링층
3. MLP층
4. 소프트맥스층

- 3×3 작은 필터를 여러 개 쌓아 깊은 신경망의 효과를 입증한 모델 (VGG-16 / VGG-19)

> [!note] 큰 필터 하나 vs 작은 필터 여러 개
> - 3×3 필터 2번 사용 vs 5×5 필터 1번 사용 → 둘 다 5×5 영역의 특징을 뽑을 수 있음
> - 연산량: 3×3 두 번 = 18, 5×5 한 번 = 25 → 작은 필터 여러 개가 더 효율적
> - 필터를 여러 번 거치면서 활성화 함수도 더 많이 지나므로 레이어를 더 깊게 쌓을 수 있고, 더 복잡한 패턴 학습이 가능함

# 드롭아웃

과적합을 피하기 위해 일부 뉴런을 무작위로(랜덤하게) 비활성화하는 기법

- 학습 시에만 적용하고, 평가/추론 시에는 모든 뉴런을 사용함

# 실습 순서 (VGG-16으로 CIFAR10 분류)

1. CIFAR10 데이터셋 로드 + 데이터 증강(RandomCrop, RandomHorizontalFlip) + 정규화(Normalize)
2. `torchvision.models.vgg.vgg16` 으로 사전 학습 모델 불러오기
3. 분류층(`classifier`)을 내 데이터의 클래스 수(10)에 맞게 재정의
4. DataLoader로 배치 학습 (Adam, CrossEntropyLoss)
5. 학습된 모델로 정확도 평가 → 사전 학습 없이 학습한 CNN보다 적은 에폭으로 높은 정확도
